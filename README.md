# Company Profile Contractor – Frontend (Vue.js)

Project ini merupakan website company profile contractor berbasis Vue.js (Frontend Only).
Didesain modern, responsif, dan mudah dikustomisasi untuk kebutuhan perusahaan kontraktor, portofolio, maupun proyek klien.

### Fitur Utama
- Homepage profesional dengan banner dan section informasi
- Perusahaan (profil perusahaan, tata kelola, sertifikat, partner)
- Layanan Kontraktor lengkap (renovasi, bangun rumah, interior, dll)
- Halaman Portfolio/Project dengan foto & deskripsi
- Halaman Kontak (form tampilan saja, belum terhubung ke backend)
- Header & footer responsif
- Desain modern & bersih

# Cara Instalasi

## 1. Clone Repository
```bash 
git clone https://github.com/zackyhermawan/frontend-company-profile-contractor.git
cd company-profile-contractor
```

## 2. Install Dependencies
```bash
npm install
```

## 3. Run Development Server
Gunakan perintah berikut untuk menjalankan project secara lokal:
```bash
npm run dev
```

Server akan berjalan di
```bash
http://localhost:5173
```
